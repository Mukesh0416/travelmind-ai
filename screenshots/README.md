# TravelMind AI - Screenshots

This directory contains screenshots of the TravelMind AI application for the GitHub portfolio.

## How to Capture Screenshots

1. Start the application:
   ```bash
   python run.py
   ```

2. Open your browser at: `http://localhost:8501`

3. Capture each of the following screens:

| # | Filename | Description |
|---|----------|-------------|
| 1 | `01_home_page.png` | The main landing page with title, subtitle, and navigation sidebar |
| 2 | `02_travel_form.png` | The trip planning form with destination, days, travelers, budget, travel style, and interests |
| 3 | `03_weather_section.png` | Weather results showing temperature, humidity, and wind speed |
| 4 | `04_attractions_section.png` | Recommended attractions and places to visit |
| 5 | `05_hotel_recommendations.png` | Hotel recommendations with names, price ranges, and descriptions |
| 6 | `06_restaurant_recommendations.png` | Restaurant recommendations with names, cuisines, and costs |
| 7 | `07_transportation_recommendations.png` | Transportation options and travel tips |
| 8 | `08_packing_recommendations.png` | Packing checklist organized by category |
| 9 | `09_itinerary_page.png` | Day-by-day itinerary with activities and meals |
| 10 | `10_travel_history_page.png` | Travel history showing past trips |
| 11 | `11_user_preferences_page.png` | User preferences with travel style and favorite activities |

## Tips

- Use **Windows + Shift + S** to capture a specific region.
- Or use the browser's built-in screenshot tool (F12 > Capture).
- Save all screenshots in this `screenshots/` directory.
- Ensure each screenshot is clear and readable.
